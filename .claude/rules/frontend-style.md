# Frontend style

The short universal rules stay in `agent_docs/CLAUDE.md` (no inline `style`,
tokens not literals, icons from one module). This is the rest.

## UI copy

Text a player reads says what is there, never why or what happens next. The
author removes anything more, so write it short the first time.

- A title names the thing: `World map`, `Saves`, `Screenshots`.
- A detail line holds facts only: a size, a count, a date
  (`286 MB · last written Oct 20, 2026`, `615 MB · 140 pictures`).
- No reasons, consequences or how the app works: not "the map you explored",
  "put back on every Play", "kept so the download can continue".
- Do not repeat what a title or button already says: no "Delete 512 MB?"
  beside a Confirm button.
- No sentence chained with "so", "because", "as" or "which". Two short
  sentences, or one.
- A warning is earned only by a loss the player cannot undo, such as files
  deleted outside the bin.
- Test: delete the text. If the player still knows what to do, leave it out.

## Tokens are not edited here

`src/styles/tokens.css` and `src/styles/tokens.ts` are generated by
`pnpm gen:tokens` from `design/tokens.json`. To add or change a value, edit the
source and regenerate; commit all three outputs (the third is
`backend/design/design_gen.go`). A hand edit is reverted on the next run.

`src/styles/base.css` is what the app shares with the download site: the
`@font-face` rules, the base element rules, and the scrims over artwork as
`@utility scrim-hero` and `scrim-wash`. `src/style.css` imports it after
`tokens.css` and adds only what the app alone needs (the full-height root, no
text selection, `.art-pending`). Neither holds a literal design value: every
size, spacing, percentage and weight in them is a `var(--…)` from the tokens,
and the `no hand-written design values` invariant refuses arbitrary
`tracking-[…]`, `brightness-[…]`, pixel `size-[…]` and literal `color-mix()`
percentages. A component's look is its utility classes.

## Utilities the token layer provides

Colours: `bg-sunken bg-canvas bg-raised bg-raised-2 bg-hover`,
`text-fg text-fg-soft text-fg-muted text-fg-faint`, `border-line
border-line-strong`, `text-accent bg-accent bg-accent-wash border-accent-edge`,
`text-success text-warning text-danger` (and `value-tone`, a readout whose colour fades
through the three as its value gets worse: `RangeField`'s `tone`, the memory slider), and `bg-chapter-<id>` for the rare place a chapter's
colour is needed outside its own scope. Type: `text-2xs` to `text-2xl` and
`text-display`; `font-ui font-display font-mono`; `tracking-control
tracking-label tracking-eyebrow`. Radius: `rounded-sm rounded-md
rounded-lg rounded-pill`. Motion: `duration-fast duration-slow ease-standard
ease-out` (`duration-dwell` is the site's hold between chapters; the app
does not use it). Layout: `w-(--layout-sidebar)`, `h-(--layout-hero)`,
`h-(--layout-titlebar)` (`-mac` on macOS), `size-(--layout-icon-sm)` and `-md`. Effects:
`hover:brightness-(--effect-hover-brightness)`, `scrim-hero`, `scrim-wash`.

Motion utilities, in `style.css`, built from the motion tokens (`duration-fast`
`-reveal` `-page` `-grace` `-slow` `-drift`, `effect.revealBlur`,
`layout.revealRise`, `effect.glow`): `reveal` and `reveal-wait` (a page's body
once loaded, and the faint line while it is not: `ui/Reveal`), `page-in-right`
`page-out-right` `page-in-top` `page-out-top` (a page sliding over the chapter
card: `main/PageLayer`), and `glow-accent` and `glow-danger` (a filled button's
hover glow, never on a disabled one). Each has a reduced-motion fallback that
only fades and still ends its animation, because a leaving page is unmounted
by its `animationend`.

Size changes animate in one place, not per component. `ui/Smooth` (with
`lib/smoothResize`) is the box of every `SettingsCard`, `Dialog` and the
sidebar's downloads section: its height follows its content over the reveal
and whatever is added to it later fades in (`smooth-resizing`,
`smooth-enter`). A new card or popup gets that by being drawn with one of
them; draw a new kind of tile with `Smooth` rather than animating its parts.
`ui/Grow` stays for a line or block that comes and goes (it also fades it
out), and the box follows it. An element that takes a control's place grows
out of it with `morphFrom`, shrinks back into it with `morphTo`, and carries
`data-smooth="self"` (the Java argument field).
A column's popup is the column lifting out: the surface starts as the column,
carrying a copy of it that fades as it rises, while the column stays empty
(`rise-in`, `rise-out`, `lift-ghost-out`, `lift-ghost-in`, `rise-content-in`,
`wash-in`, `wash-out`; Dialog's `origin` and `lifting`). The launch intro
(`shell/LaunchIntro`) runs its timeline with the Web Animations API from the
same tokens (`ms`, `token` from `lib/smoothResize`), and a line too long for its place fades at its
end (`fade-end`) rather than ending in an ellipsis where a control sits over it.

Every `ui/Scrollable` glides on the wheel (`lib/smoothWheel`): WebKit moves a mouse wheel's
steps at once.

Spacing is Tailwind's default 4px scale, which is what the reference was drawn
on; `p-14` is 56px. Do not add a spacing token for a value the scale already has.

## The accent

`--accent` is set by `data-chapter="<id>"` on the root (App does it) and read by
`text-accent` and friends. A subtree that must show a *different* chapter's
colour sets its own `data-chapter`, which is how the sidebar rows each glow in
their own colour while the page is on another chapter. Never write a chapter's
hex or a per-chapter class in a component.

## Themes

Dark is the default. `data-theme="light"` on the root switches the palette;
with `theme: 'system'` the attribute is removed and the media query decides.
Every colour token has a light value, so a component never needs a `dark:`
variant. If you find yourself writing one, the token is wrong.

## Icons

`components/ui/Icon` is the single render path; the glyph comes from
`lib/icons.ts` as a component. A control's icon goes inside
`components/ui/IconButton`, which owns the hit area, hover and accessible name;
the icon itself stays `aria-hidden`. Adding an icon is one line in `icons.ts`.
The busy mark is `ui/Spinner`, never a rotated icon: WebKit draws an SVG turned by
CSS at a shifting fraction of a pixel, so it wobbles (WebKit bug 252385).

## Placeholders

The manifest writes an unsettled fact as `[PLACEHOLDER]` or `null`.
`lib/manifest.ts` (`isPlaceholder`, `factValue`) is how a component asks;
`components/ui/Fact` shows one faint rather than hiding it.

## Stores

One per domain (`useChapterStore`, `useEngineStore`, `useSettingsStore`,
`useServerStore`, `useGameStore`, the account page's `usePlayerStore`, and the
settings page's `useTerrainStore` and `useTailscaleStore`, which the sidebar's
downloads section, loaded after the first paint, also listens through, and
What's new's `useWhatsNewStore`, loaded with its popup); a
component reads with a selector and never reaches into another store's data.
`.claude/rules/ipc.md` has the rejection rules.
